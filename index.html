What’s on the ISO

Linuxium doesn’t reinvent the operating system. It picks solid parts, sets them up so they look and work together, and leaves everything else in Debian’s archive one apt install away.

Base
Debian 12 “Bookworm”
Desktop
Cinnamon, with the Nemo file manager
Login screen
LightDM, with the Tux wallpaper behind it
Apps
Firefox ESR, LibreOffice Writer and Calc, VLC
Sound and network
PipeWire and NetworkManager
Installing
Try the live session first, then install from it
Hardware
64-bit, 2 GB of RAM, 20 GB of disk

Put it on a USB stick

  1. Download the latest ISO from the Releases page.
  2. Write it to a USB drive of 4 GB or more with balenaEtcher, or Rufus in DD mode. This erases the drive.
  3. Restart and open the boot menu (usually F12, F10, Esc, or Del), then pick the USB drive.
  4. Choose the live session to look around, or the installer to put Linuxium on your disk.

Secure Boot isn’t supported yet. If the stick won’t start, turn Secure Boot off in your firmware settings.
